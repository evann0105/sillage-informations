Assistance

Version 2026-11-08.1

Version de test personnel. Sillage n’est pas encore publiée sur les boutiques.

Contacter Sillage

Écrivez à s.sillage@outlook.fr pour obtenir de l’aide ou poser une question sur vos données.

Décrivez le problème, le modèle du téléphone, sa version iOS ou Android et la version de Sillage. N’envoyez pas de photos ou de vidéos personnelles. Aucun média ni journal n’est joint automatiquement ; vous choisissez le contenu de votre message avant de l’envoyer.

Une photo ou une vidéo ne s’affiche pas

Sur iPhone, un média présent uniquement dans iCloud nécessite une connexion et un compte Apple fonctionnel. Vérifiez la connexion, puis utilisez Réessayer. Vous pouvez aussi passer le média sans le marquer comme trié.

Sillage prépare les médias suivants dans une fenêtre limitée. Le premier chargement d’un média absent du téléphone peut prendre du temps. Une vidéo iCloud lente peut continuer à charger ; après une attente prolongée, une nouvelle tentative manuelle est proposée.

Modifier l’accès à la galerie

Ouvrez les réglages de votre téléphone, puis les autorisations de Sillage pour les photos et vidéos. Les choix proposés dépendent de votre version du système. En accès limité, seuls les médias autorisés sont visibles et comptés.

Le retrait de l’autorisation ferme l’accès aux médias concernés. Il ne revient pas sur les suppressions ou les ajouts d’album déjà validés.

Annuler un choix ou retrouver un élément supprimé

Annuler revient sur le dernier choix de tri encore disponible. Écarter prépare une sélection ; le fichier n’est supprimé qu’après votre validation. Annuler ne restaure pas un fichier déjà supprimé par le système.

Sur iPhone, ouvrez Photos puis Supprimées récemment pour récupérer un élément encore disponible ou l’effacer définitivement. Sillage ne peut pas vider cet album. Avec Photos iCloud, les suppressions peuvent être synchronisées sur vos autres appareils.

Sur Android, la suppression utilisée peut être définitive. Ne comptez pas sur une corbeille. Avant Android 11, la protection des favoris n’est pas proposée : vérifiez manuellement la sélection.

Progression et données locales

La progression est enregistrée sur votre appareil. Sillage ne possède pas de copie distante permettant de la restaurer. Effacer les données de l’app ou la désinstaller peut supprimer cette progression, sous réserve des sauvegardes système.

Les documents de confidentialité décrivent le traitement local, les caches, iCloud, les sauvegardes et les messages adressés volontairement à l’assistance.
